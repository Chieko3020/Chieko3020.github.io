网易云api说明

  • api 自建 api
  • 基于 NeteaseCloudMusicApiEnhanced 实现的网易云音乐 API, 支持跨域请求，返回 APlayer 格式并缓存。
参数 必传 取值范围 说明
type 是 song, playlist, radio, search, album, artist, lrc, url, pic 请求资源类型
id 是* 数字 资源 ID（search 类型除外）
keyword 否 字符串 搜索关键词（仅 search 类型必传）

注：当 type=search 时，必须传入 keyword 参数而非 id。

  • 单曲解析: https://music-api.chieko3020.xyz/?type=song&id=2733777862

  • 歌单解析: https://music-api.chieko3020.xyz/?type=playlist&id=14424322349

  • 播客解析: https://music-api.chieko3020.xyz/?type=radio&id=1228381556

  • 歌曲搜索: https://music-api.chieko3020.xyz/?type=search&keyword=初音ミク

  • 歌词获取: https://music-api.chieko3020.xyz/?type=lrc&id=2733777862
